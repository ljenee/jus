#이미지 소싱·편집 이미지 다운로드하기 이미지 정렬 및 폴더정리 M이미지/목록이미지 제작 인트로이미지 제작

VVIC 이미지 소싱·편집

중국 도매 플랫폼(VVIC)에서 신규 상품 이미지를 소싱하고, 회사 쇼핑몰 운영 기준에 맞게 편집합니다.

메인·상세 이미지 용도에 따라 크기를 조정하고, 필요한 이미지를 선별·가공한 후 업로드용 파일로 제작합니다.

01

이미지 다운로드하기

⬆️ 이미지 클릭 시 사이트로 이동 → 로그인후 메인페이지 진입

🖍️ 상품메뉴 → 마진율 계산 클릭

미등록 상품 검색하는 법-🅐

🖍️ 최초입고일을 직전 한달로 기간을 잡는다 → 작업상태를 작업전으로 바꾼다 → 검색클릭

미등록 상품 검색하는 법-🅑

🖍️ 작업자란에 '입고중' 입력 → 검색클릭

🖍️ 입고가 완료되었거나, 입고예정(입고중)인 상품확인하기

🖍️ 작업자 이름으로 변경하기(작업자 본인 이름) → 작업 전 상태에서 작업중 상태로 변경하기 → 제품 페이지 링크 클릭하기
작업 진행사항 [작업중] [작업완료] 체크 / ★비고 코멘트 잘 읽기★
중복 작업 되지 않도록 변경 후에는 마진율 페이지 새로고침 한번씩 해주세요!

⬆️ 제품페이지 링크(VVIC)에 진입한 상태

🖍️ 다운로드 클릭 → 상품 이미지 및 동영상 다운로드 시작됨
상품 이미지가 부족하거나, 화질이 안 좋을때, 제품과 비슷한 상품 검색 버튼 눌러서 검색하기
재검색 해도 이미지가 없다면, 타오바오에서 이미지검색해서 이미지 다운 받기(수동/로그인필요)

⬇️ 다운로드 완료되면 아래 [이미지 정렬 및 폴더정리] 순서로 넘어가기

02

이미지 정렬 및 폴더정리

⬆️ Adobe Bridge 열기
파일명 일괄변경/이미지크기 일괄변경/확장자 일괄변경 용
윈도우는 알씨로도 사용가능(사용법은 블로그 검색해서 참고)

⬆️ 다운받은 상품 이미지 압축파일 확인

🖍️ 압축을 풀고 폴더를 열어주세요 → 중국어 폴더 2개 혹은 3개 중에 [商品详情页图] 폴더를 열어주세요

⬆️ 디테일이미지(상품 정면 샷/확대 샷)는 저장명 [d0x] 으로 변경
디테일 이미지 없으면 이 작업 생략

🖍️ 폴더내 이미지들을 색상 별로 정리한다 → 색상순서는 마진율 페이지에서 확인하기
상세페이지에 들어갈 상세이미지 순서 정하는 과정입니다.

🖍️ 정렬 된 이미지들을 전체 선택하기 → 마우스 우클릭 일괄이름바꾸기... 클릭
정렬된 이미지 순서에 따라 상품명도 그 순서대로 변경 됨

🖍️ 같은 폴더에서 이름 바꾸기(기본 설정값)
텍스트 : [ 상품코드_ ] 입력 → 시퀀스 번호 : [1] → 2자리 선택(번호 2자리 설정값) → 이름바꾸기 클릭

⬆️ 정렬한 순서대로 파일명이 잘 변경되었는지 재확인

🖍️ 임의폴더*에 상품코드명으로 된 폴더를 새로 생성 → 중국어 폴더에서 새로운 폴더로 이미지들을 모두 옮겨주세요
임의폴더* : 웹디용 작업폴더를 원하는 경로에 만들어주세요
