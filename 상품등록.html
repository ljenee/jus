#상품등록 CAFE24 상품등록법 이미지파일 업로드방법 스마트스토어 상품등록법

상품 등록

신규 상품의 기본 정보 및 옵션을 등록하고, 상품 이미지와 상세페이지를 업로드합니다.
상품명, 가격, 옵션, 재고, 카테고리 등을 확인한 후 최종 등록합니다.

01

CAFE24 상품등록법

⬆️ 이미지 클릭 시 사이트로 이동 → 로그인후 메인페이지 진입

🖍️ 상품메뉴 → 마진율 계산 클릭

미등록 상품 검색하는 법-🅐

🖍️ 최초입고일을 직전 한달로 기간을 잡는다 → 작업상태를 작업전으로 바꾼다 → 검색클릭

미등록 상품 검색하는 법-🅑

🖍️ 작업자란에 '입고중' 입력 → 검색클릭

🖍️ 업로드 할 상품선택하기 → 카페24(공구홀릭)버튼 클릭 → .csv형식으로 파일 다운로드

⬆️ 이미지 클릭 시 사이트로 이동

🖍️ 상품탭 클릭

🖍️ 상품관리 클릭 → 상품 엑셀 관리 페이지 진입

🖍️ 주소표시줄 옆 다운로드 버튼 클릭 → 최근 다운로드 기록 팝업에서 .csv파일을 드래그해서 네모칸에 드롭 → 엑셀 업로드 버튼 클릭

🖍️ 확인

🖍️ 잠시 기다리면 진행완료란에 결과값이 나타납니다.
실패 일경우 클릭하면 실패사유가 나옵니다
n개 성공 문구가 나타나면 업로드 완료

🖍️ 상품목록 클릭 → 업로드 완료된 상품명 클릭 → 팝업으로 진입

⬆️ 상품 수정 팝업 화면입니다 스크롤

🖍️ 지컬렉션 마진율 페이지(https://eclogin.cafe24.com/Shop/)에서 상품 카테고리와 계절분류를 확인 → 해당하는 카테고리 선택
→ 적용 클릭(여름,가을을 추가해야하면 SUMMER 선택후 적용클릭, AUTUMN 선택후 적용클릭 총 두번 적용을 눌러야함 )
→ 상품분류에 카테고리가 잘 적용되었는지 확인

🖍️ 메인 페이지 진열 설정에 NEW ITEM 체크 → 1+1상품 진열시 함께 체크하기
🔍 1+1상품은 세트 아이템입니다
ex)상하의세트,투피스세트,벨트세트,잠옷세트,나시가디건세트 등 두종류의 아이템이 함께 판매되는 경우

🖍️ 상품 상세 설명 - 에디봇 작성 클릭 → 확인

🖍️ 새로 작성하기 클릭

🖍️ 템플릿 - 내 보관함 - 기본템플릿 - 변경하기 클릭

🖍️ 이미지 탭 클릭 → 업로드 클릭

⬆️ 상품 상세이미지 전체 선택 후 열기 클릭

⬆️ 이미지 업로드 중 화면

🖍️ 예 클릭

🖍️ 인트로 이미지(상품코드_intro.jpg)도 업로드 하기
→ 업로드 된 인트로이미지 클릭하여 작업란으로 삽입시키기(맨 첫번쨰 이미지로 위치)

🖍️ 이미지 분류 클릭

⬆️ 이미지가 자동 분류되어 흩어져 있는 상태
🖍️ 대표색상 이미지에 적합한 이미지를 색상이미지로 드래그
상품 색상 옵션 갯수에 맞춰서 옮겨준다

🖍️ 컬러칩 영역 클릭 → 스포이드로 컬러를 고른다(색상 바를 조금씩 움직여서 가장 비슷한 컬러를 골라주세요)
→ 선택된 컬러의 HEX코드 복사 → 마진율페이지에 붙여넣기(뒤에 붙은 #xxxxxxff는 삭제)
🔍 마진율페이지 옵션컬러 코드 입력양식 : {#xxxxxx|#xxxxxx}

🖍️ 마진율 페이지에서 옵션컬려명 확인하기 → 옵션컬러명을 영문대문자로 입력하기
🏷️ 블랙 : BLACK / 화이트 : WHITE / 베이지 : BEIGE 등등
→ 대표색상 모두 선택하기(빨간색 북마크바 표시가 되어야 정상) → 수정완료 클릭

🖍️ 예 클릭

🖍️ 색상 클릭 → 대표색상 클릭 → 대표색상 004 선택

🖍️ 작업란에 대표색상이 적용(상세문구 바로아래 위치) → 수정하려는 이미지를 클릭 후 적절한 크기로 사이즈 조정하기

🖍️ 이미지 탭 클릭 → 이름순 클릭
→ 상품이미지 01번부터 마지막번호까지 클릭해서 삽입
🔍 대표컬러 바로아래에 01번이미지부터 삽입하기
⚠️ 주의 : 빠르게 클릭하면 이미지 삽입이 안되는 경우가 있습니다. 이미지를 천천히 클릭하세요.

🖍️ 4분할 영역에 디테일 이미지(저장명-d0x)를 적절한 크기와 위치로 조절하여 삽입

🖍️ 사이즈 클릭하면 상품정보가 입력란에 삽입됨 → 맨 아래(디테일뷰 아래)로 위치이동 → 상품정보 편집 클릭

🖍️ 템플릿 변경 클릭 → 해당하는 상품분류 불러오기 클릭

🖍️ 확인 클릭

🖍️ 편집완료 클릭

🖍️ 상세페이지 내용(오탈자) 및 순서를 확인 → 등록 클릭
🔍 순서 : 인트로 → 대표사진 → 상세설명문구 → 대표색상 → 이미지(01~마지막번호) → 디테일이미지(확대4분할) → 사이즈정보

🖍️ 예 클릭

⬆️ 이전 팝업창으로 복귀 → 스크롤

🖍️ 옵션/재고 설정 - 옵션값 수정 클릭

🖍️ 옵션컬러 코드 붙여넣기 → 저장 클릭
🔍 마진율 페이지에서 붙여넣기한 옵션컬러코드와 동일하게 입력

🖍️ 전체선택하기(체크) → 일괄설정 클릭

🖍️ 체크클릭 → 수량 9999입력 → 선택항목 일괄설정 클릭

🖍️ 스크롤해서 이미지정보 - 이미지등록 - 개별이미지등록 선택
→ 상세이미지 : M이미지 업로드 → 목록이미지/작은목록이미지/축소이미지 : 목록이미지 업로드

🖍️ 추가이미지등록칸에 자동으로 추가된 이미지는 모두 삭제버튼을 눌러 삭제해주세요

일반 상품 : -50% | NEW 아이콘 체크선택
1+1 상품 : -50% | 1+1 아이콘 체크선택


🖍️ 확인 클릭
